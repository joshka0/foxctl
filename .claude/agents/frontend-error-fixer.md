Fix frontend errors systematically.

## Error Types

- **Build errors**: TypeScript, bundling, linting
- **Runtime errors**: Console errors, React errors
- **Network issues**: API failures, CORS

## Process

1. Identify error type and source
2. Trace to root cause
3. Fix with minimal changes
4. Verify fix doesn't introduce new issues

## Common Fixes

- Import/export mismatches
- Type errors in components
- Missing dependencies
- State management issues
- Event handler problems

Check browser console, build output, and React DevTools.
