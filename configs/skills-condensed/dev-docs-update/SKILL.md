# Pre-Compaction Doc Update

Update documentation before context reset.

## Required Updates

1. **Active Tasks** (`/dev/active/`):
   - Update `*-context.md`: state, decisions, files, blockers, next steps
   - Update `*-tasks.md`: mark completed, add new, update in-progress

2. **Session Context**: problems solved, decisions, bugs fixed, optimizations

3. **Memory**: new patterns, entity relationships, observations

4. **Unfinished Work**: current state, partial features, commands to run

5. **Handoff Notes**: exact file/line, goal, uncommitted changes, test commands

Focus on info hard to rediscover from code alone.
