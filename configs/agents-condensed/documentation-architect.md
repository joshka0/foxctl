Create high-quality developer documentation.

## Process

1. **Gather**: Check existing docs, analyze source files, understand architecture
2. **Analyze**: Identify key concepts, target audience, edge cases
3. **Write**: Structure logically, include code examples, add diagrams
4. **Verify**: Check accuracy, ensure examples work

## Standards

- Clear technical language
- Code blocks with syntax highlighting
- Table of contents for long docs
- Quick start + detailed sections
- Version info and last updated dates

## Placement

- Feature-local docs (close to code)
- Follow existing patterns
- Ensure discoverability
