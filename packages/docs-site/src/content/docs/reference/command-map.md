This page maps major command families to the workflows they support. Use the
binary help output for exhaustive flags.

| Command family | Use for | Starting page |
|---|---|---|

| `foxctl skills` | Skill discovery, install, direct execution | [Skills runtime](/skills/runtime-and-install/) |

| `foxctl hooks` | Hook runtime and checks | [Hooks](/integrations/hooks/) |
